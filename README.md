# 钟乳石洞穴微环境巡测

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在 `data/db.json`，后续可以继续增量迭代。

## 分层

- `src/archive.js`（档案）：样点、基准版本、巡测记录的存取、履历与串行落盘。
- `src/judge.js`（判定）：按生效时刻取基准版本、三项判定、基准变更后的全量重算，纯函数可单测（`npm test`）。
- `server.js` + `public/`（页面入口）：HTTP 接口与看板 / 样点档案 / 巡测台账三个页面。

## 判定口径

- 基准按版本登记，每版记录**生效时刻**和温度 / 湿度 / CO2 三项限值（上下限）。
- 巡测按**发生当天**生效的版本判定（生效日期不晚于巡测日、生效时刻最新的一版），补录历史巡测不按今天的限值。
- 三项都在范围为「正常」，任一超限转「异常待复查」；巡测日无生效版本判「缺基准」并转待复查。
- 基准补录、修订、删除后，该样点全部巡测（含已复查记录）按新版本重算；人工复查结论不能盖住重算结果，被推翻时状态回到「异常待复查」并在履历留痕。
- 巡测台账展示每条记录采用的基准版本与三项在限 / 超限结果。
